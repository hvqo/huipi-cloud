# 教师工作台视觉与交互

工作台以教师手头的任务为中心：首页展示当前账户可读取的作业、个人阅卷任务、考试场次和异常。接口没有返回数据时显示空状态；读取失败不按零件处理。作业完成数来自现有班级作业接口，未提供或无权限读取时不推算。考试和异常仅展示受服务端分页与授权约束的有限记录，不宣称是学校全量统计。

侧栏按工作台、教学作业、考试阅卷、成绩管理和学校管理分组，允许折叠。学校管理使用 `/me/school-access`；其他考试、试卷、阅卷和成绩入口根据已有服务端能力或可访问资源列表显示。可见菜单只是导航提示，每次操作仍由原业务接口重新鉴权；当前接口没有提供覆盖所有未来资源的全局菜单权限合同，因此没有可访问对象时相关入口可能不显示。创建或获授权后切换页面会重新读取；连续切换时导航请求有短暂节流。成绩和学生数据不因显示菜单而扩大授权。

页面遵循统一蓝白灰色彩、清晰的中文字号、轻边框及明确的主次操作。作业支持本页筛选与卡片/列表；分卷保留三栏工作区；阅卷保留原页、作答和人工复核相邻的位置；长表格在窄屏横向滚动。缺评、未发布、保存结果未知等提示始终保留。截图使用隔离环境的合成资料，不代表真实学校数据。

设计参考：[飞书工作台](https://www.feishu.cn/content/3c6y1qwl) 的个人待办和工作入口组织，[vue3-element-admin](https://github.com/youlaitech/vue3-element-admin) 的 Vue 与 Element Plus 管理界面结构，以及 [Element Plus](https://element-plus.org/zh-CN/) 的基础交互组件。项目使用自主实现的布局与样式，没有复制参考项目源码或品牌素材；图标使用 Element Plus 维护的图标包。

## 工作区布局

首页以自适应网格突出待处理阅卷任务；作业、考试、异常和快捷入口按重要性分配空间，空数据和读取失败仍分别显示。扫描接收与人工分卷将页面导航、原卷预览和操作区并列；阅卷工作区将原页缩略图、可缩放原卷和作答确认／审核并列，原卷随页面滚动保持可见。窄屏时恢复纵向排列。

成绩工作区只展示服务端返回的所选版本、所选已授权班级的数据；分数段及各题得分率按班级与卷别分别呈现，学生详情在抽屉中查看。未发布版本不伪造统计。试卷编辑保留题目切换的未保存修改检查，并在同一工作区相邻展示题目、标准答案与评分项；个人阅卷与作业提交状态筛选均只作用于当前已加载页。

所有布局仅重排现有业务数据和操作，权限、历史版本、来源校验和成绩发布规则仍由服务端执行；显示范围不等于新的授权。
