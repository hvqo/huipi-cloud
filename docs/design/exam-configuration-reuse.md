# 考试配置页面的兼容复用

开发前只读检查PR #31的真实HEAD `4aed261fd3c119bcbef077afbab2561767283c8d`，查看
`AppShell.vue`、`EmptyState.vue`及其路由/服务目录。它包含另一套demo-auth、Mock/Real Adapter和lucide依赖，
不能作为当前考试HTTP合同的直接替代。

本切片沿用当前main的Vue、Element Plus、PageState、认证内存会话、侧栏与页面间距；没有合并PR #31，
也没有导入旧的模拟业务成功逻辑或增加组件库。页面采用三步分区：用卷、名单、后续处理。
名称、学科、学校时间、班级、考号和卷别优先；UUID仅用于实际资源引用，不充当页面主标题。

冻结区只读、更正草稿明确显示旧版仍有效、未保存修改阻止冻结。结果未知提示在实际操作对话框内可达，
允许重试原请求；不会靠Toast或固定等待时间制造成功。后续扫描/批改/成绩使用既有路由，不复制工作区。

这是一轮业务配置界面，不宣称完成整套前端视觉体系升级或正式教师可用性研究。
