# 答题卡 OMR 合成验收

本记录只针对平台 A4 单选模板的合成样本，不代表真实学校、设备或学生笔迹的识别准确率。

## 样本与运行边界

真实 OpenCV 对模板生成的图片执行定位与识别。确定性样本覆盖：黑色单选、未填涂、多涂、浅灰填涂、模糊、透视偏移、错误模板及缺定位标记。未通过定位或标记校验的页面被拒绝；弱填涂标记为待核验；空白和多涂不生成建议分数。阈值是本实现的初始保守设置，尚未针对真实扫描仪和笔迹校准。

独立 PostgreSQL、私有 S3、真实 FastAPI 与 Chromium 运行了浏览器闭环：选择锁定试卷 → 创建并下载打印 PDF → 对下载的合成 PDF 添加两处模拟填涂 → 扫描接收 → 人工分卷并选择冻结名单中的学生 → 识别 → 显示原图定位区域 → 教师批量确认 → 整卷成绩预览。两道合成题识别 A、B，教师确认后分别得到 10.00 分，预览总分为 20.00；该结果未发布。浏览器套件 4 项通过，5 项按既有条件跳过。

真实 PostgreSQL/S3 专项同时验证了仅确认一题时另一题保持空分、教师明确确认空白后才计零、Excel 导出、跨用户拒绝、并发确认、答卷更正后旧记录失效、历史数据库不可变、撤权后重放拒绝、私有预览字节损坏拒绝、审计失败回滚与 COMMIT 确认丢失后的原请求恢复。迁移在独立数据库完成 upgrade、Alembic check、downgrade 和再次 upgrade；存在 OMR 业务事实时拒绝破坏性降级。

本轮没有使用真实学生数据、收费模型或新的模型权重。合成 PDF 的绘制不等价于实体打印、拍照、纸张污损、光照或不同笔迹的现场测试。正式大规模使用前仍需学校使用合规授权数据开展设备校准和人工复核验收。
