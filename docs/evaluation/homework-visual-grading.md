# 日常作业图片评分合成验收

2026-10-30 00:38（上海时间），在独立 PostgreSQL、私有测试 S3、真实 FastAPI 与 Chromium 环境，使用合成学生、两班作业和一张合成 PNG 验证了图片评分。浏览器完成代收、框选、发送图片、读取建议、教师接受、查看班级进度和重交；重交后当前提交的复核数由 1/1 变为 0/1。旧版本的结果没有用于新提交。

本次视觉请求实际使用 `deepseek-flash`、OpenAI-compatible 接口及 disabled Thinking；服务端发送了一个裁剪 PNG。只调用一次，没有自动重试。模型返回 `finish_reason=stop`、1 个带 `image_region` 的候选，合成题建议 2.00/2.00，随后由教师在浏览器接受。模型响应报告输入 712 Token（其中缓存命中 128、未命中 584）、输出 155 Token、模型调用耗时 1492 ms。以 DeepSeek [公开定价](https://api-docs.deepseek.com/quick_start/pricing/)的非高峰单价估算约 0.000181 美元；实际账单由服务商计费决定。视觉开关只在本次隔离进程中显式启用，没有修改用户配置。

该图片的公式是人工制作的合成印刷文字；模型证据描述将其称作手写，这是语义判断的局限。此结果证明图像真实传输、协议校验和教师复核闭环，不证明真实手写、数学表达或任一学科的教学评分准确率。图片路径不依赖解析成功；浏览器环境中后台解析器为明确标记的合成测试执行器，并非本次真实 MinerU 验收。图文混合与异常协议另外在隔离数据库中使用合成测试 Provider 验证，未冒充真实模型结果。

自动 CI 不调用收费 API。模型弃权、证据不合格、服务故障或未复核均不会自动记零；教师应核对图片证据及评分理由。模型调用结果未知时先查询任务，不对同一选区自动重试。
