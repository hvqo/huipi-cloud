# 考试图像评分：合成链路验收

本记录仅说明工程链路，不是教师双评或真实学科评分质量评测。测试使用隔离 PostgreSQL、私有测试 S3、真实 FastAPI 和 Chromium；考生、考试、教师、答题内容均为合成数据。开发数据库没有参与。扫描 PDF 用绘图程序模拟中文笔画、算式、几何图形和混合页序，不能代表真实手写难度。

## 实际调用与复核

使用机器已有的 MinerU Basic 缓存完成答卷解析，未下载模型。通过浏览器上传、人工分卷和确认合成学生身份后，教师在两页原始扫描预览中框选两个区域。一次 DeepSeek Flash 请求将两张服务端裁剪 PNG、题目、标准答案和 Rubric 一起发送；实际响应模型字段为 `deepseek-flash`，无思考模式、最大输出 1200 Token、零自动重试。

最终一次清晰区域请求得到 5.00 / 10.00 的模型候选：模型将过程项评为 0、结果项评为 5，并给出对应区域索引。教师在浏览器接受后，成绩预览显示该生已复核 1 / 2 题、小计 5.00、整卷未完成。其他无答卷的学生未被计零。接受是合成流程验收，不表示此评分经过合格教师仲裁。

单独发送一张全白的合成图片作为证据不足探针，最终模型返回 `grading_abstained` 且没有总分。它覆盖材料不可判读的情况，但不能代表真实模糊手写的识别表现。数据库专项测试另外验证弃权及要求人工判读不会形成有效分数。

## 请求记录与协议修正

本轮合成数据共发起 6 次真实 API 请求，均获得 HTTP 响应。没有自动重试或删除失败记录：

| 请求 | 图片 | 原始响应及当时的服务端结果 |
| --- | --- | --- |
| 跨页 1 | 2 | 返回候选；多了固定 `type=json_object` 元数据，原严格解析拒绝 |
| 跨页 2 | 2 | 返回候选；省略服务端选定的协议版本，原严格解析拒绝 |
| 跨页 3 | 2 | 视觉合同元数据兼容修正后通过，并完成浏览器教师复核和成绩预览 |
| 证据不足 1 | 1 | 返回弃权；附带空的顶层证据列表，原严格解析拒绝 |
| 证据不足 2 | 1 | 兼容修正后接受弃权，不产生分数 |
| 跨页 4 | 2 | 加入文本/图像来源切换保护后，最终代码重新完成真实浏览器评分与复核 |

视觉响应合同现在只接受固定值 `type=json_object`，省略版本时使用服务端已选择的 `1.0`，并仅允许弃权携带空的顶层证据列表。冲突版本、非空顶层证据和未知字段仍被拒绝。评分项、Decimal 上限、总分及逐项图像区域证据检查没有放宽。对早期原始响应的离线解析不改变原来失败的任务状态；它们不算作当时的有效候选。

六次请求合计输入 5,458 Token、输出 1,397 Token，服务端报告延迟分别为 2,451、2,334、2,032、1,083、1,075 和 1,869 毫秒。按 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)的 Flash 峰时未命中输入每百万 0.30 美元、输出每百万 1.20 美元计算，不抵扣缓存命中及低峰优惠的保守估算约 **0.003314 美元**；实际扣费以服务商账单为准。

## 自动化验证与限制

隔离 PG/S3 测试覆盖跨页选择、原页绑定、作答区域更正、撤权与迟到结果、模型弃权、人工接受与逐项修订、Excel 小计、清除后旧结果失效。测试评分器只用于这些确定性回归，不能冒充真实模型调用。自动化不调用收费 API，真实模型验收必须显式 opt-in。

这不是全学科、真实照片、真实手写或多人教师评分准确性评测。模型对中文笔画、图形和过程的解释仍可能错误；教师须核对原图及理由。当前要求答卷已完成受保护解析，不处理扫描失败或解析失败后直接评分。图片无法辨认时可弃权或人工处理，不自动补零。
