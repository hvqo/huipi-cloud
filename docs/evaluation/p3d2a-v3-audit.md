# P3-D2A v3：参考标签审计与模型错误归因

## 范围与来源完整性

本审计只读取冻结的 v3 合成数据、60 次历史模型响应和原始评测文件，不调用模型，不改题目、标签、预测或预注册条件。v3 数据 SHA-256 为 `de59c65d31669043ffd49c062318861a542bd039cfd04c7df4d4645dc4df620d`；v1 准入条件 SHA-256 为 `8d4de2bdf2691ad2e494e343af22702665f2aface31eb521e4492700b3a5c861`。原始预测、原始报告、历史摘要和复核清单也通过冻结清单的 SHA 校验。

机器逐案校验数据结构与引用，作者对 60 条案例进行了一轮技术一致性筛查。该筛查不是合格教师复核或教师双评。审计报告中的每个 `human_review_status` 都是 `unreviewed`；“未发现具体问题”不能解释为标签已获认证。

- 53 条参考评分案例在本轮技术筛查中未发现明确的题干、AnswerKey、Rubric、分值或引用冲突。它们仍是 `synthetic_curated_reference`，不是教师验证标签。
- 5 条原本已标为 `excluded_uncertain` 的案例继续没有参考分数，保留为材料不确定的弃权探针。
- `v3-stem-copy-number` 是题目材料不完整。
- `v3-econ-opportunity-cost` 的 10 分参考标签存在评分解释争议。

逐案结论与来源哈希保存在[版本化审计报告](../../data/evaluation/grading/rubric-cases-v3-audit-v1.json)及其 SHA-256 sidecar。6 个分数差异、缺图弃权失败与重复 Quote 拒绝组成[版本化质量回归清单](../../data/evaluation/grading/p3d2a-error-regression-v1.json)。清单不是人工复核记录，状态保持 `unreviewed`。

## v3-stem-copy-number：题目没有给出所需数据

题干要求用货车行驶距离和时间求平均速度，但没有给出实际距离或时间；Rubric 的公式项要求写出关系并代入数据，单位项要求根据具体数据给出数值和单位。学生只写“距离÷时间，单位km/h”。参考 0 分无法区分“学生未代入已有数据”和“题干没有提供数据”。因此它不是材料完整的普通评分案例，原标签不能证明学生应得 0 分。

保留 v3 与历史 6 分模型响应，不纳入事后分数敏感性分析。若需修复题目，应新建数据集版本，明确题干数值，重新独立编写参考标签，并重新请求模型；旧响应不能用于新题目。

## v3-econ-opportunity-cost：保留标签争议

题目语境说学生为参加培训放弃周末兼职收入；学生回答“机会成本就是放弃的兼职工资”。参考 10 分有合理依据：最佳替代收益及具体兼职收入都能从上下文恢复。模型给 7 分，理由是答案没有明确写“最佳替代选择价值”以及培训与兼职的关系。

现有 Rubric 将“最佳替代选择价值”和“把定义用于培训与兼职选择”拆成两个 5 分 Criterion，但没有说明答案可否依赖题干上下文、短语是否足以满足两项。技术审计不能替代教研判断，故将其标为 `reference_label_dispute`；不宣称参考 10 分或模型 7 分为权威结果，也不自动改标签。该案例从事后敏感性分析排除，须由合格教师审定标准答案与分项边界。

## Quote定位指标：保留两种分母

预注册文件 v1 原样保留。其文字条件是“被接受候选中的 Quote 全部唯一精确定位”，所以 v1.1 按有效候选内部 Quote 重算该门槛。原始 Quote 监控仍保留所有协议有效的模型引用，包括候选被拒绝时的引用失败。

| 指标范围 | 精确定位数 / Quote数 | 结果 | 失败记录 |
| --- | ---: | ---: | --- |
| 全部原始模型 Quote | 100 / 101 | 99.01% | `v3-quote-short-duplicate` 有 1 条 `quote_ambiguous` |
| 通过完整校验的候选 Quote | 99 / 99 | 100% | 无 |

重复短 Quote 导致整条候选被拒绝。拒绝后，它仍保留在全部原始 Quote 的 100/101 监控中；不会把 100/101 改写成 100/100。被接受候选 Quote 的定位本身是确定性候选验证器的通过条件，因而接近结构性必然；它不能替代原始引用监控，也不能证明 Quote 在语义上支持评分。

原摘要 `quality-summary.json` 与 v1 准入文件均未改写。统计范围修复生成独立的 [`quality-summary-v1.1.json`](../../data/evaluation/grading/deepseek-flash-grading-v3-2026-10-14-run-01/quality-summary-v1.1.json) 和对应[人工复核清单](../../data/evaluation/grading/deepseek-flash-grading-v3-2026-10-14-run-01/human-semantic-review-v1.1.json)。Quote 门槛按原文定义由历史误判的失败改为通过，预注册通过项因此从 7/12 变为 8/12；分数指标、数据、模型预测、失败原始记录及其他门槛均未改变。总体仍不满足生产准入，人工语义门槛仍未完成。若未来希望要求所有原始模型 Quote 均唯一匹配，应在下一版预注册条件里单列，不得回改 v1。

## 六个评分差异的技术分类

下面是对题目、Rubric、学生原文、参考标签与模型理由的初步比较。分类可重叠；参考标签来自合成整理，尚未由教师审定。正面错误案例表示模型的得分与当前 Rubric 字面要求存在明确矛盾，不表示已完成教学评分认证。

| 案例 | 参考 / 模型总分 | 初步类别 | 可核对的问题 |
| --- | ---: | --- | --- |
| `v3-linear-arithmetic-slip` | 5 / 8 | `incorrect_arithmetic_credit`, `incorrect_method_credit` | 学生写 `x=3.5`，Rubric 要求正确计算 `21÷7`；模型给除法项 3/3，且理由承认结果错误。 |
| `v3-mixed-right-wrong` | 5 / 8 | `incorrect_arithmetic_credit`, `incorrect_method_credit` | 学生写 `x=6`，Rubric 要求 `x=5`；模型给除法项 3/3，并称错误结果证明完成步骤。 |
| `v3-partial-quarter` | 5 / 10 | `missing_conversion_credit` | 学生停在 `75000 cm`；模型把应换算的 `750 m` 写进理由，却给换算项 5/5。 |
| `v3-english-keyword` | 0 / 4 | `keyword_only_credit` | 学生只列出 `oxygen` 等词；模型把字词出现当作“氧气是产物”的关系说明。字面 Quote 可定位，但不支持该语义。 |
| `v3-stem-copy-number` | 0 / 6 | `source_incomplete`, `incorrect_method_credit`（暂定） | 模型承认无数值代入仍给公式项满分；但题目缺少必要数据，因此不能把这条直接作为可评分质量样本。 |
| `v3-econ-opportunity-cost` | 10 / 7 | `rubric_interpretation_disagreement`, `reference_label_dispute` | 模型和合成参考对“定义/应用”拆分口径不同；无教师仲裁前不认定模型错或参考正确。 |

前四项是适合进入下一轮回归测试的明确风险：错误算术仍得步骤分、错误结果仍得方法分、遗漏单位换算得满分、单个关键词替代语义关系。后两项分别需要先修复来源材料和先完成参考标签仲裁。`quote_ambiguous` 是来源定位/候选覆盖失败，不应混为评分语义错误。

这些差异是从真实模型保存的原始理由、原始 Quote 和分值读取，没有修正输出，也没有据此调整参考分。Quote 被精确定位只说明字符串来自指定学生片段；是否足以支持给分需要人工判断。

## 来源缺失、错误答案与零分不是一回事

`v3-uncertain-missing-image` 的关键图像来源不可用，因此该案例没有确定参考分，也没有进入 55 个计分样本。弃权探针中模型仍返回 0 分候选，并将“图像缺失、无法读取角度”说成学生未完成。它混淆了来源不可用与学生答错/未作答；不能把候选 0 分当作有效评分。

后续正式评分流程应在调用评分模型前执行 Source Readiness 检查，依据可信来源状态，而非只读学生文字中的“图片缺失”提示：

1. `ready`：解析任务完成，Canonical 页面和资源清单完整，Rubric 所需的图文来源已解析，教师确认的作答区域及 GradeInput 覆盖完整。
2. `needs_source_repair`：解析失败、资源清单缺项、图片不可读或页面被裁切；先修复来源。
3. `needs_teacher_review`：来源归属、作答区域或歧义需人工确认。
4. `unsupported_modality`：当前评分输入无法完整表达该题所需图片、公式、表格等证据。

非 `ready` 状态应拒绝生成候选评分或转人工处理，并记录来源准备状态；不能据此判定学生错误，也不能自动写 0 分。可信输入应结合 ParsedArtifact 状态、Canonical 资源清单及哈希、人工确认范围和评分输入准备结果。此项是后续设计建议，本轮没有更改 P3-A/P3-B 协议或生产评分流程。

## 事后敏感性分析

以下仅从 v3 原始预测中排除 `v3-stem-copy-number` 和 `v3-econ-opportunity-cost` 两条争议标签；没有新请求，没有重写参考分，没有重算或更改 v1 预注册准入结果。其余 53 条已标注案例里有 52 条形成有效候选。

| 指标 | 事后敏感性结果 |
| --- | ---: |
| 有效候选 | 52 / 53 |
| 总分完全一致 | 48 / 52 |
| 总分绝对误差和 / MAE | 15 / 52 = 0.2885 分 |
| 总分高估 / 低估 | 4 / 0 |
| Criterion 完全一致 | 109 / 113 |
| Criterion 绝对误差和 / MAE | 15 / 113 = 0.1327 分 |
| Criterion 高估 / 低估 | 4 / 0 |
| 高风险零分参考案例 | 1 / 8 有效候选正分：`v3-english-keyword` |

这是事后分析，不能改变 60 次运行的原始基线，也不用于宣称模型性能更好。v1 主结果继续是 54/55 有效候选；有效候选上总分 48/54 完全一致、MAE 24/54 = 0.4444；逐项 110/117 完全一致、MAE 24/117 = 0.2051。v3 仍是合成集，不代表真实高中作业准确率。

## 下一轮质量回归优先级

1. 对明确要求正确值或正确变换的 Criterion，测试模型不得把“执行过错误步骤”当作满分依据。
2. 将模型理由与得分逐项核对，拦截“明确说步骤错误/缺失但仍给该项正分”的自相矛盾。
3. 为简短关键词构造只含词汇、没有关系/解释的对照样例；要求人工审读 Quote 的语义充分性。
4. 在评分前完成可信来源就绪门禁，将缺图、缺页、OCR不可辨和 Rubric 不可判定分开处理。
5. 由教师仲裁 `v3-econ-opportunity-cost` 标签；对缺数据的速度题创建新版本后再请求模型。
6. 单独监控全部模型 Quote 的歧义失败；不要用已通过候选的 100% 定位率掩盖被拒绝引用。

在完成教师标签复核与真实作业双评前，不进入 P3-D2B 生产集成。即使合成集所有数字门槛通过，也不能自动发布成绩。
