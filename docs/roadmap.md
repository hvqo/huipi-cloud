# 项目路线图

以下内容是后续计划。除本次交付的最小工程骨架、配置读取、基础日志、健康检查和对应单元测试外，其余能力均尚未实现。

## P0：工程骨架与基础设施

- 补充环境分层、配置校验、结构化日志、统一错误处理和服务就绪检查。
- 建立代码质量与持续集成约定，并明确本地开发和部署方式。
- 按实际需求评估并引入数据库、对象存储和异步基础设施。

## P1：作业提交、原始文件存储、任务管理

- 建立教师侧作业提交与作业元数据管理。
- 设计原始文件上传、访问控制和存储生命周期。
- 管理解析、批改任务状态及失败重试。

## P2：OCR/MinerU 多模态解析与题目结构化

- 接入 OCR/MinerU 等解析能力，处理扫描件、图片和 PDF。
- 将题目、学生作答和版面位置转换为可追踪的结构化数据。
- 建立解析结果校验与人工纠错流程。

## P3：标准答案管理、Rubric 评分、AI 自动批改 Agent

- 管理标准答案和可配置评分 Rubric。
- 设计可追溯的评分结果与理由。
- 在边界明确的任务中实现自动批改 Agent，并提供失败回退。

## P4：教师 Copilot、检索与工具调用

- 为教师提供围绕作业和批改结果的 Copilot 能力。
- 建立受权限约束的检索与上下文组织。
- 为工具调用设计输入校验、权限边界和执行记录。

## P5：教师复核、异步任务优化、模型推理与性能评测

- 支持教师复核、修改和反馈记录。
- 优化异步任务吞吐、可观测性和资源使用。
- 评估模型推理部署方案，并建立质量、延迟和成本评测。
