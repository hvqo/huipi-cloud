# 项目路线图

## P0：工程骨架与基础设施

- 已有：Python 3.12 与 uv 工程、src 包、FastAPI、基础配置和日志、健康检查、pytest 与 Ruff。
- 本轮补充：PostgreSQL Async 持久化、Docker Compose 本地数据库、Alembic 迁移和 GitHub Actions 基础检查。
- 后续计划：结构化日志、统一错误规范、生产环境配置校验、监控与部署流程。

## P1：作业提交、原始文件存储、任务管理

### P1-A：核心数据模型与教师作业管理

- 本轮实现：Assignment、Question、AnswerKey、RubricCriterion 数据模型；草稿创建、题目、人工答案、评分细则、详情查询和发布完整性检查。
- 当前不包括学生提交、作业文件上传、任务队列或教师权限。

### P1-B：作业提交与任务管理

- 规划：教师作业入口、原始文件存储、上传元数据、解析和批改任务状态、失败重试。
- 尚未开发。

## P2：OCR/MinerU 多模态解析与题目结构化

- 规划：接入 OCR/MinerU 处理图片与 PDF。
- 规划：将版面、题目和作答转换为可追踪的结构化结果。
- 规划：建立解析质量检查和人工纠错流程。

## P3：标准答案管理、Rubric 评分、AI 自动批改 Agent

- 规划：扩展标准答案管理和 Rubric 版本。
- 规划：实现可追踪、可解释的自动批改 Agent 与失败回退。
- 当前答案只能由教师接口写入；模型生成答案与自动批改尚未实现。

## P4：教师 Copilot、检索与工具调用

- 规划：围绕作业与批改结果提供教师 Copilot。
- 规划：加入受权限约束的检索、上下文组织和工具执行记录。

## P5：教师复核、异步任务优化、模型推理与性能评测

- 规划：支持教师复核、修改和反馈记录。
- 规划：优化异步任务吞吐、可观测性和资源使用。
- 规划：评估模型推理部署，建立质量、延迟和成本评测。
