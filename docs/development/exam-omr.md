# 答题卡与客观题人工确认

`/omr` 提供 A4 答题卡创建、打印、识别和教师确认。扫描接收、人工分卷和学生身份确认继续使用现有考试流程；识别程序不读取文件名推断学生，也不按上传顺序关联身份。

## 模板与题目

- 创建模板要求对目标 `PaperVersion` 同一 Grant 具备 `paper.read` 和 `paper.edit`，卷版必须已锁定且内容和映射摘要一致。每个锁定卷版当前只允许一个不可变模板；题目变化应 fork 新卷版，再建模板。
- 首版最多 30 道四选一单选题，显示题号须为 12 字符以内的 ASCII。标准答案须是教师维护的单个 `A`、`B`、`C` 或 `D`，Rubric 总分必须与题目满分一致；其他题型、答案表示和中文题号不进入模板。
- 每个模板题目通过真实 `PaperQuestionMapping` 外键绑定卷版。打印 PDF 含四角定位标记及由模板 ID 派生的机器可读模板校验标记；该标记不包含学生身份，不是学生身份识别功能。
- 模板内容、识别结果及教师决定只追加保存。数据库阻止事后增加模板题目、改写历史，阻止不同卷版和答卷页串接，并核对最终选择与题目分值。

## 识别与确认

识别只处理当前完整、已确认身份且来源、冻结名单和实际卷别有效的答卷。服务端从有序答卷版本选择真实扫描页，校验 Manifest 及原文件、页面大小和 SHA；调用方不能提交对象存储路径、分值或学生身份。处理使用有界图像，OpenCV 找四角并透视校正，校验模板标记后在指定区域计算填涂密度。不能可靠定位、模板不符或页面模糊时拒绝识别。

识别输出分为 `single`、`blank`、`multiple`、`uncertain`。只有清晰单选产生候选分值；空白、多涂和模糊无自动分数。教师可以对照带区域框的扫描原图批量确认自己已核对的清晰结果，也可逐题明确选择 A–D 或人工确认空白。后一种情况下，确认空白后才可记零；没有确认的空白、多涂、模糊或缺页不是零分、缺考或正式成绩。

确认保存当前操作者、时间、题目、选项、分数、修订序号及源识别记录。确认权限复用同一场次 Grant 的 `exam.mark.read`、`exam.score.review`、`exam.script.read`、`exam.identity.verify`，并另要求该场次 `exam.roster.read`；所有读取、保存与重放重新核验当前授权及来源。请求 ID 幂等，不接受调用方提交分数。结果预览与 Excel 在服务端使用当前答卷、锁定卷版和最新教师确认重新计算分数；失效来源不再计入，历史记录保留。

首版不覆盖其他厂家版式、非 A4、多选题、多页模板、自动身份识别、阅卷双评或正式成绩发布。定位码与填涂检测并不证明教学语义，也不能替代教师查看原图；需要在真实打印机、扫描仪、纸张和笔迹条件下另行校准阈值。低对比、擦除、污损或版面严重偏移时应人工核对或重新扫描。

## 技术参考和许可

研究了 [OMRChecker](https://github.com/Udayraj123/OMRChecker) 的模板、定位标记及扫描对齐思路，以及 [OMRSuite](https://github.com/drfperez/OMRSuite) 的四角透视校正与填涂区域灰度密度思路。两个项目各自使用 MIT 许可。本实现使用 OpenCV 与 Pillow 独立编写，没有复制其源代码或素材；测试阈值为本项目版本化配置，不代表两个项目声称的准确率。

运行依赖 `opencv-python-headless` 已锁定版本，OpenCV 主体采用 [Apache-2.0](https://github.com/opencv/opencv/blob/4.x/LICENSE)，Python 打包工程及其内含组件还各有许可证。分发安装包或镜像时应保留 wheel 自带的许可证和第三方声明；不要将依赖许可证误写成整个项目的许可证。
