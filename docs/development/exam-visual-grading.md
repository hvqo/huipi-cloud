# 考试主观题图像辅助评分

此功能在现有考试批改工作区中使用教师明确选择的原扫描页区域，对手写文字、公式或图形生成评分建议。它沿用考试评分任务、来源与授权复验、租约、人工复核及成绩预览；不会自动发布成绩。普通文本评分和标准答题卡 OMR 保持各自的证据合同。

## 启用与数据范围

图像评分默认关闭。部署人员需按现有评分指南配置 `GRADING_ENABLED`、`GRADING_PROVIDER=openai_compatible`、`GRADING_BASE_URL=https://api.deepseek.com`、`GRADING_MODEL=deepseek-flash`、有效的 `GRADING_API_KEY`、`GRADING_ALLOW_REMOTE` 和 `GRADING_EXTERNAL_DATA_AUTHORIZED`，并额外显式设置 `GRADING_VISUAL_ENABLED=true`。启动现有考试评分 Worker。远程传输的授权范围必须覆盖实际考试数据；仅打开开关不等于取得学生数据授权。CI 不配置密钥或调用真实模型。

这条路径仅允许 DeepSeek Flash 的图文接口；不会静默退回文本模型、Synthetic Provider 或其他评分策略。图像区域由服务端读取授权的私有扫描预览、校验摘要并裁剪为 PNG；客户端不能指定对象地址、原件摘要或学生身份。一次最多选择 8 个区域，每个裁剪 PNG 最大 1 MiB，坐标使用经确认页面上的整数像素。实际运行时还受原扫描预览、评分输入和 Token 上限约束。

## 教师操作

在 `/scans/sessions/{session_id}/scripts` 打开已确认且解析成功的答卷，进入「AI 批改与复核」并选择题目。在「图片作答区域」中依次选择原扫描页和框选区域；可以跨页多选、放大、移除和重新选择。确认选择后再发起图文评分。教师应避免选择与题目无关的个人信息，界面在发送前提示远程传输。

查看评分理由时可从图像证据回到原页。接受或逐项修订候选分数后才会成为该题当前教师复核结果；也可拒绝或要求人工判读。未选择、未确认、模型弃权或结果失效都不会变成零分。复选区域会形成新的版本，使旧候选不再作为当前结果；原图、旧区域和历史复核不被覆盖。

清除图像区域不会重新启用曾经的文本成绩。教师须重新确认文本作答并产生新的评分及复核，旧文本结果才不会因来源模式切换而意外回流到成绩预览。切换记录绑定实际的文本确认版本。

## 合同、安全及状态

- `POST /api/v1/exam-grading-workspaces/{id}/visual-selection` 创建、清除或更正区域，要求可信当前身份、题目来源及作答确认权限，接受请求编号和预期区域版本。
- `POST /api/v1/exam-grading-workspaces/{id}/visual-scoring` 发起真实评分任务，要求评分申请权限和当前区域版本。
- `POST /api/v1/exam-grading-workspaces/{id}/visual-score-review` 按既有考试审核权限接受、修订、拒绝或要求重新评分，接受预期审核版本。
- 当前工作区详情返回受授权的区域、候选和复核投影，不返回私有对象 Key；截图由既有受保护预览接口提供。三个接口不接收模型指定身份或自由 URL。

图像候选使用独立 `huipi.grading.visual-input`、`huipi.grading.visual-proposal` 和 `huipi.grading.visual-review` 合同，证据引用 `image_region` 的区域序号及说明。它不伪造文本 Quote，也不改变历史 GradeProposal/GradeReview 1.0。每个评分项、Decimal 分值、总分及图像证据引用均由服务端验证；引用区域存在并不证明评分理由正确，必须由教师复核。

区域、来源文件摘要与当前答卷、冻结名单、卷版、操作者授权一起参与时效校验。调用前后及最终写入仍经过原任务边界；过期租约、撤权或来源更正不能产生当前有效候选。调用结果未知时不自动重复请求；历史和可能的孤立私有对象需按既有评分产物对账规则处理。数据库迁移新增不可变区域记录及源关联；含业务事实时拒绝破坏性降级。

当前要求受保护解析已经完成，尚不支持解析失败后直接进入图片评分；不提供自动题目定位、公式正确性证明或自动成绩发布。该功能未经真实教师双评，不能将图文识别或协议通过等同于教学评分准确。
