# 异常处理与扫描补救

## 页面与真实操作

入口 `/exceptions`，按有权考试/科目场次汇总当前待处理事项；扫描接收、人工分卷、阅卷管理及进度页提供数量和快捷入口。页面20秒刷新，其他工作区徽标30秒刷新，返回浏览器时也读取当前状态。它是实时业务投影，不是另建一套异常工单或评分协议。

可用处理路径：

1. **上传失败/租约过期**：原上传人从异常行重新选择相同文件名与内容的PDF，沿原 `scan-batches/{id}/files` 和原 request_id 恢复同一 ScanFile。后端再次验证SHA、大小、文件名、当前权限及尝试Token；不能用旧键换文件。其他有权操作员可新建同场次补扫批次，失败历史保留。结果未知时保留文件对象和原请求，人工重试，不自动生成新键。
2. **未认领或疑似重复页**：原页JPEG预览、原件下载都调用已有受保护接口，字节/SHA限制及Event/Session授权不变。补扫批次与当前答卷可跨文件、跨批次关联，但必须同场次。
3. **缺页/页序/身份待核验**：定位到准确的答卷编辑面板，添加页面、调序、保存新版本并从当前冻结名单重新选择身份和卷别。跨批补页不覆盖ScanFile/Page，不延用未经核对的身份。修复了旧深链接的嵌套busy导致无法打开编辑面板的问题。
4. **解析失败**：定位原答卷核对原因；来源坏损先补扫，资源故障排除后明确重新确认生成新AnswerScriptVersion，再点开始解析。仍是一版本一个Job，旧失败Job/输入/产物保留，不能复活旧任务或无限自动请求。来源/名单/卷版/授权不符仍拒绝。
5. **作答未确认、AI失败/弃权**：进入关联答卷的原批改工作区，按异常显示题号人工核对，再沿原作答确认和评分接口处理。当前任务教师进入本人的任务；没有名单、扫描或全场次授权的教师不会取得全场次资料。
6. **阅卷来源/授权失效**：负责人可在原进度界面撤回未完成的旧任务，在新有效答卷工作区重新派单。已完成但失效的旧任务不能直接撤回，保留待人工跟踪，其历史不会阻止新答卷派单。旧评分不重新纳入成绩，未完成不补零；缺扫描或缺页不推断缺考。

## 权限与API

仅新增两个GET：

- `/api/v1/recovery-sessions?offset=0`：20场次/页，SQL按现有真实Scope过滤；task.work岗位须已有本人current任务。
- `/api/v1/exam-sessions/{session_id}/exceptions?offset=0&kind=...`：25条/页，有界类型枚举；`summary=true`只读统计，不返回明细。

复用当前 OIDC/JWT、User 和密封 Role/Grant。文件、页面、答卷、解析、评分、负责人任务与本人任务分别按原动作组合过滤。需要同Grant的动作仍必须在同一Grant中具备；解析/评分另需同场次名单读取权。没有新增管理员捷径、自由Scope、权限自动分配或特权Session。旧作业HTTP/Worker隔离不变。

task.work教师只能看到自己具体任务对应的异常，不会因为异常中心获得其他题、其他班、全校名单、原卷PDF或完整试卷权限。读取投影不代表获准修复；每个原写接口都重新授权和校验revision/request_id、来源及审计。

投影仅返回类型、受控资源ID、文件名/页码/题号、时间和固定中文原因；不主动读取学生姓名字段、作答、标准答案、Rubric、Token、原始异常堆栈或S3私有Key；有权查看的原文件名可能包含操作者输入的信息。原上传人且仍有上传权限时才返回重试request_id。修复所有写入继续由原服务完成，没有新增业务表、迁移或危险更新接口。

## 统计与来源边界

- 一个对象可能有多种待办，异常总数是条目数，不是学生数、缺考数或成绩数。
- “已接收文件/已确认完整答卷/当前解析成功答卷”是现存业务结果数量，不冒充累计修复量。列表随current版本、冻结名单、卷版和当前Grant变化更新，不通过隐藏旧失败记录虚报修复。
- 未认领页按当前占用表判断。重复页只按同场次预览SHA相同提示，可能是正常空白页；不删除、不合并、不自动判错。
- 完整性来自人工声明，当前没有可信页数模板，因此不能自动定位缺少哪一页、识别倒序或判断智能错页。可在原工作区核对和调整。
- 数据库状态投影不逐份下载S3或重新运行OCR，不是持续文件健康监测。特殊的权限目录禁用、角色配置错误或授权数量超限仍需到原业务入口核验。实际预览、确认、解析消费、评分和成绩读取继续执行既有SHA/版本/租约检查。
- 未发到服务器的客户端上传失败、登记前拒绝的非法PDF不会生成数据库异常条目，上传页面仍显示真实错误。接受端资源上限保持32MiB/50页；答卷仍100页、8文件和原来源核验预算。
- 暂未建立“人工忽略疑似重复”的持久工单、已完成失效任务的人工关闭、工单负责人/SLA、自动修复、智能缺页检测或收费模型重试。无法处理的条目保持待人工核验，不伪造已解决。

默认CI不运行真实服务/模型；本切片回归的Synthetic解析/评分只验证业务状态与合同，真实MinerU/DeepSeek效果沿用既有验收资料，不冒充新模型验收。
