## 3. 建议定稿的技术决定（待本轮审查确认）

- D01 单校；行政班/教学班/考场独立，考试时保存班级快照，不建多租户框架。
- D02 Session≠Assignment；一个共享 PaperVersion 对应一个锁定内容载体，可跨班/跨场次复用；A/B 使用显式映射，不按班克隆。
- D03 新 ScanBatch/File/Page 和 ScriptVersion 独立于单份 Submission；纯人工分卷可先上线，未知身份/场次不自动正式归属。
- D04 每个核实答卷版本独立桥接旧 Submission，稳定内部 ref，不取消旧唯一键，不覆盖旧文件/解析/复核历史。
- D05 Role+固定 Permission+类型化 Scope；任教关系不直接授阅卷权；新考试资源从旧 admin/全作业读权限中隔离，匿名访问须题区级。
- D06 MarkingPlan/Task/Record 独立；候选/人评/有效题分/快照/发布分别建模；先单评，再双评仲裁，B 不开放正式成绩。
- D07 改来源先阻断受影响/未知依赖，再逐页验证；不能声称现有整卷SHA已支持精确局部评分复用。
- D08 大批次采用独立有界接入，不借旧20MiB接口；S3/PG保留未知COMMIT对象，用操作日志与原请求恢复，不宣称Exactly Once。

## 4. 需要学校确认的政策（不以默认猜测补齐）

| 事项 | 在确认前的安全默认 | 阻塞的实际阶段 |
|---|---|---|
| 学生名册可信来源、责任人与必要字段 | 合成名单开发，不导真实身份 | B真实试用 |
| 扫描设备、尺寸/双面/PDF/网络条件 | 网页受控PDF上传，纯人工分卷；容量实测前不定SLA | B设备/容量 |
| 同名/无身份材料核验依据和责任 | 保持未认领，不按收卷顺序自动绑定 | B真实归属 |
| 匿名跨班是否全覆盖、自己班回避 | 默认匿名；无安全裁剪不发题区，自己班回避规则须配置确认 | D上线 |
| 双评阈值/合分/选做/舍入规则 | 不擅自采用均分或强制零分 | D-2/E |
| 作业重交、补扫/补考有效尝试选择 | 新版保留，需明确确认才切当前有效 | B-2/修复 |
| 试卷/规则不同是否允许比较 | 显式不同版本，未经审核不排名 | E分析 |
| 成绩审批/发布人员、对象、更正/申诉窗口 | 发布关闭，先内部预览 | E-2 |
| 外部模型处理真实答卷授权与部署条件 | 不发送真实学生资料，云生成仅授权范围 | 真实模型试用 |
| 保留/备份/删除审批、小群体结果隐私 | 不自动清理历史/公开排名；实施前制定策略 | 真实数据上线 |
| 自定义岗位高敏双人审批名单/破窗机制 | 高敏动作默认关闭，最小授权 | B权限高敏/E |
| 题库Word导入/组卷需求 | 非扫描MVP前置，后续另立切片 | 后续 |

本文件是工程方案，不代学校完成政策或法律适用性审批；没有开展法律合规结论推断。

## 5. 当前风险与进入下一阶段条件

- 现有 is_admin 有全局教学资料权限；未实现新分类/隔离前，不得开放匿名考试任务或给扫描员旧 admin。
- Submission 的一次提交、ParsedArtifact 的单一成功产物不能原位扩成版本；桥接必须与旧提交注册同事务。
- 没有可信题目必需材料声明、学校真实标注/双评质量数据；不承诺自动手写阅卷质量，Quote v2 不转正式评分默认。
- PR #31 和 7 个本地视觉提交尚需分别审查，不能在文档PR里顺便合并；后端第一切片可独立推进，前端基线合入顺序需确认。
- 本轮没有新业务数据/DDL/模型调用；部署库版本与真实学校负载未验证。

第一条实现闭环由 B-1.1～B-1.5 完成；下一轮可先执行 B-1.1 的组织/权限隔离，不必再改动核心术语和链路。下一轮开始前需独立批准本轮 D01–D08，明确可信名册责任人（可先合成）、冻结该切片API/迁移和验收用例。学校尚未确定双评/发布规则不阻塞人工扫描 MVP，但相关功能保持关闭。
